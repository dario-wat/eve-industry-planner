eve-esi

One package for EVE SSO + ESI. It replaces eve-sso and eve-esi-client. The library handles auth and makes requests; the app stores the tokens.

Who owns what

Library — packages/eve-esi
  • Login URL, code exchange, token refresh
  • JWT signature check (node:crypto, cached CCP keys)
  • Deciding when to refresh (60 s before expiry)
  • One shared refresh per character for parallel requests
  • HTTP: User-Agent, query, JSON body, x-pages
  • Typed errors
  • 16 endpoint methods + getAll*
  • ESI response types (Esi*)
App — server
  • Storing tokens in MySQL (load / save)
  • Choosing which token row to use (scope matching)
  • Creating accounts and characters after login
  • Linking characters to Account
  • Login state, sessions
  • Caching (EsiCache)
  • Deciding what failure means (null, skip, rethrow)
  • gen / genx naming

Config & types

// Full client (server)
const esi = new EsiClient({
  userAgent: USER_AGENT,
  sso: {                      // optional
    clientId, secretKey, callbackUri,
  },
  tokens: {                   // optional
    load: (characterId) => store.genTokenSet(characterId),
    save: (characterId, set) => store.genSave(characterId, set),
  },
});

// Public-only client (ping / market history Lambdas)
const esi = new EsiClient({ userAgent: USER_AGENT });
type EsiTokenSet = {
  accessToken: string;
  refreshToken: string;
  expiresAt: Date;
  scopes: string[];
};

type EsiTokenHooks = {
  load(characterId: number): Promise<EsiTokenSet | null>;
  save(characterId: number, set: EsiTokenSet): Promise<void>;
};

type EsiLoginResult = {
  characterId: number;
  characterName: string;
  ownerHash: string;
  tokens: EsiTokenSet;
};

type EsiPage<T> = { data: T[]; pages: number };

Known issues

Documented, not fixed in this project — except where the migration fixes them anyway.

"Logged in" means access token not expired

A character counts as logged out ~20 min after its last use and is then skipped, so it never refreshes. Trading Lady only stays alive via the 5-minute Lambda.

EsiCharacter.isLoggedIn, ActorContext.genLoggedInLinkedCharacters

Fixed SSO state

The login state is a constant from .env, so the callback has no CSRF check.

EveLoginController

Several token rows per character

The schema allows many tokens per character, chosen by scope match. One row per character would be simpler.

esi_tokens, EsiTokenStore.load

Refresh race across processes

The server and a Lambda can refresh the same character at the same time. The shared refresh only works within one process.

Trading Lady: server + order-book Lambda

gen* never returns nullFIXED BY MIGRATION

logEsiErrorAndReturnNull calls e.json(), which doesn't exist, so it throws. Goes away with the gen* variants.

Error status never loggedFIXED BY MIGRATION

pageErrorMessage reads statusCode, which the error doesn't have. Switches to EsiError.status.

Public Lambdas need ESI secretsFIXED BY MIGRATION

new EsiClient({ userAgent }) needs no SSO config.

Lambda zip misses eve-esi-clientFIXED BY MIGRATION

packageLambda.mjs copies eve-sso but not eve-esi-client. It will copy eve-esi.
